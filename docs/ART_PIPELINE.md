# Art pipeline (procedural pixel art)

All world art is hand-tuned **procedural pixel art** generated by Python scripts in `Tools/PixelArt`. The PNGs are
committed under `Assets/Resources`, so nothing has to be run to build the game.

| Script | Draws | Output | Size |
|---|---|---|---|
| `gen_tiles.py` | 13 tile kinds x 15 floor themes, with variants (floor 4, wall 3, rock 3, prop 2, water 2) | `Resources/Tiles/<theme>/<kind>.png` | 32 px per tile, horizontal variant strip |
| `gen_characters.py` | 12 playable characters (+ `player`), 4-frame idle and 4-frame walk | `Resources/Sprites/character_<id>.png`, `..._move.png` | 32 px frames |
| `gen_creatures.py` | every enemy, miniboss, boss and companion in the content JSON, idle and (if it moves) move strips | `Resources/Sprites/<spriteKey>.png`, `..._move.png` | 24 to 96 px frames, sized from the collision radius |
| `gen_items.py` | every item icon, plus pickups, bombs, shots, pedestal, exits, hazards, shrines (several animated) | `Resources/Sprites/item_<id>.png` etc. | 16 / 24 / 32 px |

Shared drawing helpers (palette ramps with hue shift, shaded ellipses lit from the top left, light ordered dithering,
outlines, shadows, strip saving) are in `px.py`. `preview.py` makes an enlarged preview sheet.

## Running

```
pip install pillow numpy
python Tools/PixelArt/gen_tiles.py
python Tools/PixelArt/gen_characters.py
python Tools/PixelArt/gen_creatures.py
python Tools/PixelArt/gen_items.py
```

Output is deterministic (seeded by id) and takes seconds.

## In game

- Art is drawn at 32 pixels per world unit with point filtering; the camera zooms by a whole number and snaps to the
  pixel grid so pixels stay square (`RunDirector.UpdateCamera`).
- A sprite PNG that is wider than it is tall is a strip of square frames (`PlaceholderArt.LoadFrames`). Actors play the
  idle strip at 4 fps and the `_move` strip at 9 fps while moving, and face their movement direction (`ActorViews`).
- Tile strips are variants; one is picked per cell by a hash of its position (`RoomRenderer`).
- `Editor/ArtImportSettings.cs` imports everything under `Resources/Sprites` and `Resources/Tiles` uncompressed, point
  filtered, without mipmaps.

Any PNG can be replaced by hand-made art at the same path and size; missing files fall back to generated shapes.
